# Snoopy Pet

Snoopy 主题的宠物动画素材包：透明 PNG 精灵图、9 组动作，以及 16 个视线方向。

本仓库保存可供接入的动画资源。运行宠物仍需单独的渲染程序或宠物应用；仓库不包含桌面程序、安装包或一键导入功能。

## 文件

- [assets/spritesheet.png](assets/spritesheet.png)：最终版 RGBA 精灵图，1536 × 2288 像素。
- [manifest.json](manifest.json)：布局、动作帧数、预览帧时长和视线方向映射。
- [previews/all-states.gif](previews/all-states.gif)：9 组动作的连续预览。
- [previews/look-directions.gif](previews/look-directions.gif)：16 个视线方向的连续预览。
- [SHA256SUMS](SHA256SUMS)：精灵图、预览和元数据的 SHA-256 校验值。

## 精灵图布局

- 8 列 × 11 行，每格 192 × 208 像素。
- 坐标原点在左上角，行号和列号从 0 开始。
- 动作从每行第 0 列开始，按从左到右的顺序播放。
- 共 73 个有效单元格：57 个动作帧和 16 个视线姿态。其余 15 格完全透明。

| 行号 | 状态 | 有效帧数 | 含义 |
| --- | --- | --- | --- |
| 0 | `idle` | 6 | 待机、呼吸、眨眼 |
| 1 | `running-right` | 8 | 向右跑动 |
| 2 | `running-left` | 8 | 向左跑动 |
| 3 | `waving` | 4 | 挥手 |
| 4 | `jumping` | 5 | 跳跃 |
| 5 | `failed` | 8 | 失败或受阻反应 |
| 6 | `waiting` | 6 | 等待输入或帮助 |
| 7 | `running` | 6 | 工作或思考 |
| 8 | `review` | 6 | 查看已完成的结果 |
| 9 | 视线方向 | 8 | 0° 至 157.5°，每格递增 22.5° |
| 10 | 视线方向 | 8 | 180° 至 337.5°，每格递增 22.5° |

视线角度以向上为 0°，顺时针递增：90° 向右、180° 向下、270° 向左。中性姿态可使用第 0 行、第 0 列。每个角度的具体位置见 `manifest.json` 中的 `look.frames`。

## 接入方式

1. 下载仓库，或克隆：

   ```sh
   git clone https://github.com/F-86/snoopy-pet.git
   ```

2. 读取 `manifest.json`，加载 `atlas.path` 指向的 PNG。所有资源路径都相对于仓库根目录。
3. 根据行、列裁取单帧：

   ```text
   x = column × 192
   y = row × 208
   width = 192
   height = 208
   ```

4. 播放某个动作时，只读取该行前 `frame_count` 格，跳过透明空格。`preview_frame_durations_ms` 记录原 GIF 中每帧的毫秒数，可作为播放节奏参考；实际循环、状态切换和交互由接入程序决定。
5. 视线帧是按方向选择的离散姿态，可根据目标方向选择最接近的角度。预览中的顺时针轮播仅用于展示。

`manifest.json` 是本仓库整理的资源描述文件，并非任何应用的官方安装清单。原始精灵版本为 2；这不代表已验证第三方应用兼容性。

## 已知细节

- 视线帧由离散姿态组成，部分相邻角度切换仍有轻微跳变；接入时可根据需要增加过渡。
- PNG 已有透明背景，无需再做色键抠图。不要把 GIF 的展示背景当作原始素材背景。
- 仓库只保留最终资源及使用说明，不包含生成过程中的中间图、提示词或完整 QA 归档。

## 校验

在仓库根目录执行以下任一命令，可检查资源是否完整：

```sh
sha256sum -c SHA256SUMS
```

macOS 可使用：

```sh
shasum -a 256 -c SHA256SUMS
```
